01

The Guard

What Gary actually does

Watches, never drives

Gary is a sentry, not a driver. Every surface in this project reads public data and reports it. Nothing here holds a key, signs a transaction, or moves a balance on anyone's behalf.

Quoted by contract, never by name

The readout prices this token by its contract address, from the deepest pool it trades in. A copycat mint using the same ticker cannot inherit this quote, because the ticker is never what is looked up.

A shallow pool is not a price

Any pool below the stated liquidity floor is reported as too thin to quote rather than printed as a number. A fifty-dollar puddle moves 40% on one buy, and a market cap built on it is fiction.

A dark feed is not a zero

When an upstream stops answering, the last good reading stays on screen, visibly aged, and the status lamp turns. It is never replaced by $0.00 — the difference between "we cannot see it" and "it is worthless" is the whole readout.

No write path, and none planned

The backend serves GET and nothing else, and a test in the repository fails the build if any other method ever appears. Buying happens in your own wallet on a DEX you choose — never through a server sitting on a public URL.
